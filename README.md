# NSFW 占位符反混淆还原器 (astrbot_plugin_nsfw_restorer)

专门用于规避上游大模型提供商（如 Google Gemini / Vertex AI 等）敏感词过滤与 400 拦截的 AstrBot 输出层插件。

---

## 📌 解决的核心痛点

在进行无拘无束的情感与亲密创作时，上游 API 经常会因为检测到敏感生理词汇或直白描写而触发 400 报错、返回空消息或封禁请求。

本插件利用 **占位符混淆 + 后端无损反混淆还原** 的设计范式：
1. **上游生成阶段**：模型在生成文本时使用约定的安全占位符（例如用 `[§p§]` 代表肉棒，用 `[§v§]` 代表小穴）；
2. **网关审查阶段**：发往和来自 Google API 的上下文均为代号字符串，无法被关键词规则命中，畅通无阻；
3. **输出拦截阶段**：在 AstrBot 准备将消息发送给用户前的 `@filter.on_decorating_result()` 最终阶段，插件自动将所有文本组件中的占位符无损替换回真实大白话，呈现在用户终端上的依然是毫无阉割、字字到肉的真实文本。

---

## ⚙️ 配置说明 (WebUI 原生支持)

插件附带标准 `_conf_schema.json`，已无缝接入 AstrBot 控制台面板。进入 **插件管理 -> astrbot_plugin_nsfw_restorer -> 配置** 即可直观操作：

| 配置项 | 类型 | 默认值 | 作用说明 |
| :--- | :--- | :--- | :--- |
| `enabled` | `bool` | `true` | 是否全局启用占位符反混淆还原 |
| `log_restorations` | `bool` | `true` | 是否在控制台输出每次匹配还原的词汇统计日志 |
| `mappings` | `object` (Key-Value) | 见下表 | 占位符与目标词汇的映射字典。**可以在 WebUI 面板中直接查看对应名、修改目标词、或添加全新的映射对！** |

## 🛠️ 自定义与拓展

在 AstrBot 管理面板中，你可以随时往 `mappings` 里添加你需要的任何映射，比如：
- Key: `[§cervix§]`  ->  Value: `宫颈`
- Key: `[§dildo§]`   ->  Value: `假阳具`

插件会在每次消息处理时自动热重载配置并重新编译正则树，无需重启机器人即可生效！
